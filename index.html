01 · evaluation harness

ragcheck ↗

A local, offline evaluation harness for RAG pipelines. Computes precision@k, recall@k, MRR, and hit rate, with a BM25 baseline retriever built in — no API keys or GPU required. Includes a groundedness check that flags generated answers not well-supported by retrieved context.

An MCP server that gives AI agents a persistent, stateful Jupyter kernel instead of one-shot sandboxed execution. Ships with diagnostic tools to inspect in-scope variables, profile pandas DataFrames, and validate SQL query plans before execution.

03 · CLI tool

A pandas-native diff tool that detects data quality drift between two DataFrames — schema changes, new nulls, distribution shift (PSI), and cardinality changes. Ships as a CLI supporting CSV/Parquet/JSON, with a CI-friendly exit-code mode and a test suite.
